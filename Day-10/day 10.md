# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my academic background, interests, skills, and aspirations as a Psychology student exploring the intersection of human behavior and technology.

## Features

* Responsive design
* Dark/Light mode toggle
* Smooth animations
* Interactive UI elements
* Skills and interests showcase
* Contact section
* Modern glassmorphism-inspired design

## Tech Stack

* HTML
* Tailwind CSS
* JavaScript

## About Me

I am a Psychology student passionate about understanding human behavior, mental health, and cognitive science while exploring the potential of AI and digital technologies to create meaningful impact.

# Think Like a Marketing Strategist: Grow This Brand

## Overview

Think Like a Marketing Strategist: Grow This Brand is an interactive learning application that teaches users how marketers make strategic decisions rather than simply generating marketing content.

Users can either analyze their own business, build a personal brand strategy, or work with a randomly generated client to experience real-world marketing decision-making.

The application combines marketing education, strategic thinking, and prompt engineering into a single interactive experience.

---

## Features

- **Three learning modes:**
  - Use My Own Business
  - Build My Personal Brand
  - Random Client Challenge
- Audience analysis with beginner-friendly explanations
- Social media platform selection with strategic reasoning
- Content pillar generation and prioritization
- Interactive 30-day marketing roadmap
- Randomized real-world marketing events
- Growth Report with strategic feedback
- Prompt engineering cards after every major section
- Progress tracking
- Responsive dark-themed interface
- Fully offline
- Single HTML file
- Built with React via CDN

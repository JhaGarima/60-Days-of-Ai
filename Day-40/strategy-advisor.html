How this was built

System prompt design

The model is instructed to act as a blunt, senior strategy consultant — not a cheerleader. It's constrained to return strict JSON only (no prose wrapper), with a fixed schema: four SWOT arrays (each item paired with a one-line "why it matters"), plus a single verdict object containing a recommendation, its reasoning, a priority tag, and a numeric confidence level. Forcing structure this way means the UI never has to guess how to parse the model's answer.

Edge cases are handled inside the prompt itself: if the situation is too thin to analyze responsibly, the model returns an insufficient_info flag naming exactly what's missing, rather than inventing plausible-sounding filler. If the input is off-topic, abusive, or an attempt to extract the system prompt, it returns a short refusal flag instead of a SWOT. The interface checks for these flags before trying to render a grid.

Why the UI looks like this

A generic chat bubble would undersell what's actually a structured analytical output, so the result renders as a war-room pinboard: four bordered quadrants color-coded by valence (teal for strengths, brick-red for weaknesses, brass for opportunities, violet for threats), each item styled like a pinned note with its rationale in a smaller italic line underneath. The verdict is set apart as a stamped card with a priority tag and a confidence bar, because a strategy session that doesn't end in a clear call to action hasn't actually done its job.

Extending this

  • Multi-step flow: chain a second call that takes the verdict and drafts a one-page board memo, or generates the three biggest follow-up questions a skeptical exec would ask.
  • Memory: persist past briefs (e.g. via localStorage or a backend) so a team can track how a decision's SWOT shifted quarter over quarter.
  • Tools: wire in a web-search tool so competitor claims get checked against current public information rather than the model's own knowledge.
  • Collaboration: let multiple stakeholders submit context separately, then have the model reconcile conflicting views of the same situation before producing one brief.

# Day 47 – Content Intelligence Studio

## Overview

Content Intelligence Studio is a premium AI-powered content analysis application designed to help creators, marketers, founders, and businesses improve their content before publishing.

The application conducts an interactive interview to understand the user's objectives, then performs a comprehensive AI-driven review using multiple specialized reviewers. It accepts both text and image uploads and generates platform-specific recommendations through live Claude Messages API calls.

Unlike traditional analyzers, every insight, explanation, recommendation, rewrite, score, and prediction is generated dynamically by Claude rather than hardcoded logic.

## AI Review Workflow

The application intelligently builds a review pipeline depending on the uploaded content.

Possible reviewers include:

- Content Strategist
- Platform Growth Expert
- Copywriting Specialist
- UX Reviewer
- Thumbnail Reviewer
- Hook Optimization Expert
- Behavioral Psychology Reviewer
- SEO Specialist
- Engagement Analyst
- Brand Consistency Reviewer
- Storytelling Expert
- Conversion Optimization Reviewer

Each reviewer receives a dedicated production-grade system prompt and independently evaluates the content through Claude.

# Day 9 – NutriScope Nutrition Dashboard

## Objective
Learn how AI can be used to rapidly generate and improve a complete nutrition-tracking web application.

---

## MVP Version (Prompt 1)

Features:
- User profile inputs
- Nutrition target calculation
- Food logging
- 20-food database
- Macro and micronutrient tracking
- Dashboard with charts
- Personalized recommendations
- Responsive dark UI

---

## Enhanced Version (Prompt 2)

Additional Features:
- CSV import/export
- Expanded food database (60 foods)
- Additional micronutrients
- 2-day meal planner
- Nutrition risk analysis
- Educational disclaimer
- Nutrition data sources
- Advanced charts
- Improved recommendation engine

---

## Key Learnings

1. AI can generate complete frontend applications from detailed prompts.
2. Prompt quality strongly influences output quality.
3. Iterative prompting can significantly improve software functionality.
4. Comparing versions helps identify feature expansion and UI improvements.
5. AI-assisted development can accelerate prototyping and idea validation.

---

## Comparison Summary

| Feature | MVP | Enhanced |
|----------|-----|-----------|
| Food Database | 20 Foods | 60 Foods |
| CSV Upload | No | Yes |
| Meal Planner | No | Yes |
| Risk Analysis | No | Yes |

---

## Reflection

This exercise demonstrated how AI can be used as a rapid prototyping partner for building data-driven web applications. The enhanced version showed how additional requirements can be layered onto an existing product through iterative prompting.

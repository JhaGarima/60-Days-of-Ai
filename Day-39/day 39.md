# Day 39 - PDF Splitter & Merger

## PDF Splitter & Merger

A premium single-page HTML application that performs complete PDF splitting and merging directly inside the browser without requiring any backend or server.

Built as part of the **#60DaysABTalksChallenge**.

---

## Features

### PDF Splitter

- Upload PDF files
- Automatically detect total pages
- Generate page thumbnails
- Preview uploaded document
- Split by:
  - Individual page numbers
  - Custom page ranges
  - Every N pages
  - After specific pages
  - Multiple ranges in one operation
- Extract selected pages
- Live validation of page ranges
- Preview output before processing
- Download generated PDFs

---

### PDF Merger

- Upload multiple PDFs
- Drag and Drop support
- Sort files before merging
- Preview uploaded PDFs
- Display:
  - Total files
  - Total pages
  - Estimated output
- Merge into a single PDF
- Download merged PDF

## Technology Used

- HTML5
- CSS3
- Vanilla JavaScript
- PDF.js
- pdf-lib

Everything runs entirely inside the browser.

No backend.

No data upload.

Offline capable after the initial library load.

---

## How to Run

1. Download the HTML file.
2. Open it in any modern browser.
3. Upload PDF files.
4. Split or merge them.
5. Download the processed PDFs.

No installation required.

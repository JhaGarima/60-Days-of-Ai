# Prior Authorization Story Simulator

An interactive educational web application that explains the Prior Authorization process through branching conversations, realistic healthcare scenarios, and guided decision-making. Users follow a patient's journey, explore different choices, and learn how prior authorization works in a simple and engaging way.

## 📌 Overview

This project demonstrates how AI can generate a complete educational application that combines storytelling, healthcare education, conversation-based learning, and modern web development.

Instead of reading lengthy documentation, users experience the approval process through an interactive story where every decision influences the conversation.

## ✨ Features

- Interactive healthcare story with branching dialogue
- Conversation-style chat interface
- Eight story chapters covering the complete journey
- Choice-based progression after every scene
- Patient journey following Rahul's prior authorization process
- Healthcare guidance from Priya at each stage
- Dynamic progress bar throughout the application
- Final approval outcome with key learning takeaways
- Replay functionality to explore alternate dialogue paths
- Responsive HTML application generated entirely with AI

## 🚀 How to Run

1. Clone or download this repository.
2. Open `PriorAuthorizationStorySimulator.html` in any modern web browser.
3. Start the interactive story.
4. Make decisions throughout the journey.
5. Complete all eight chapters.
6. Replay the simulator to explore different dialogue paths.

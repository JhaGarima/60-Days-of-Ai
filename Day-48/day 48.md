# Day 48: Compare & Decide Builder

## Overview

Compare & Decide Builder is a research-driven decision support application that helps users compare multiple options using real, verifiable data instead of assumptions. It combines structured interviews, transparent research, adjustable decision weights, and live rankings into a single interactive HTML application.

Unlike traditional comparison tables, this tool explains exactly where every data point comes from, highlights any estimated values, and documents how conflicting sources were resolved.

---

## Features

- Interactive interview flow using multiple-choice questions only
- Collects comparison goals before generating the application
- Supports comparison of any category
- Uses only real, citable data
- Adjustable criteria weights with live ranking updates
- Transparent source panel for every data point
- Clearly marks estimates and placeholders
- Responsive premium interface
- Loading states and graceful error handling
- Collapsible "How this was researched" section
- Single-file HTML application
- No external libraries required

---

## Interview Flow

The application interviews the user one question at a time.

### Step 1
Choose what category you want to compare.

### Step 2
Define who the decision is for.

### Step 3
Select the comparison criteria.

Examples include:

- Cost
- Time
- Risk
- Quality
- Availability

### Step 4
Choose the research sources.

Either:

- Provide at least two real sources for each criterion

or

- Allow the application to research and cite reliable sources automatically

### Step 5
Choose whether rankings should be:

- Weight-adjustable
- Fixed

---

## Research Principles

The application only uses:

- Verifiable facts
- Publicly available sources
- Named citations

It never invents:

- Scores
- Benchmarks
- Statistics
- Rankings

Whenever exact information cannot be verified, the application clearly labels it as:

- Estimate
- Synthetic placeholder

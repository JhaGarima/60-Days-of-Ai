# Day 17 - Vehicle Cost Analysis Dashboard

## Overview
Built an interactive Vehicle Cost Analysis Dashboard using AI-assisted development and CSV-based data analysis. The dashboard processes vehicle operating data, calculates key performance metrics, and visualizes insights through responsive SVG charts and KPI cards.

## Objective
Create a single-page dashboard that analyzes vehicle ownership and operating costs across different fuel types, compares environmental impact, evaluates maintenance expenses, and highlights E85 fuel economics through data-driven visualizations.

## Tools Used
- Claude AI
- HTML5
- CSS3
- JavaScript
- SVG Charts
- CSV Data Processing

## Features Implemented
- Fuel-wise Cost per Kilometer Analysis
- CO₂ Emission Comparison
- Maintenance Cost Evaluation
- Refuel/Recharge Time Insights
- Vehicle Age-Based Cost Trends
- E85 Economics Analysis
- E85 Performance Scoring System
- Interactive KPI Cards
- Responsive Dashboard Layout
- Pure SVG Data Visualizations
- Glassmorphism UI Design

- Fuel Type Comparison

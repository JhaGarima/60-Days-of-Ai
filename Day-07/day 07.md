# Day 7: Personalized Claude Usage Strategy

## Objective

Learn how to use Claude more effectively by identifying the best model, effort settings, and workflow based on my academic goals, learning style, and daily tasks.

## Tools Used

* Claude AI
* GitHub

## Process

* Used the provided Claude Usage Strategy prompt.
* Shared information about my background, goals, and typical tasks.
* Analyzed my use cases as a Psychology student exploring AI.
* Generated a personalized Claude workflow and model recommendation.
* Reviewed model selection and effort-setting strategies.

## Personalized Claude Strategy

### Recommended Primary Model

**Claude Sonnet 4.6**

### Why This Model Fits Me

* Provides an excellent balance between quality and speed.
* Well-suited for learning, research, content creation, and career development.
* Handles complex reasoning while remaining efficient for everyday use.
* Supports both academic and AI-related projects effectively.

### Recommended Effort Level

*Claude recommended using Sonnet 4.6 + Standard Effort as my default setup, switching to High Effort for deeper research, complex assignments, and long-form reasoning tasks.

**Standard Effort**

This was recommended as the default setting for most daily work because it offers strong performance without unnecessary delays.

### When to Increase Effort

#### High Effort

Use for:

* Deep research
* Complex academic assignments
* Long-form content creation
* Career planning
* Multi-step reasoning tasks

#### Max Effort

Use for:

* Thesis-level work
* Dissertation research
* Advanced research synthesis
* High-stakes academic projects

## Key Learnings

* Choosing the right effort level is often more important than switching models.
* Sonnet 4.6 can handle most academic and professional tasks effectively.
* High effort should be used selectively for deeper reasoning tasks.
* Iterative prompting improves output quality significantly.
* Claude works best as a collaborative thinking partner rather than a one-time answer generator.

## Outcome

* Identified the best Claude model for my needs.
* Learned when to use different effort levels.
* Developed a personalized AI workflow.
* Improved understanding of how to use AI strategically for learning and productivity.

## Reflection

This exercise helped me realize that effective AI usage is not about always choosing the most powerful model. Instead, it is about matching the right model and effort level to the task. A structured workflow can improve productivity, learning outcomes, and project execution while saving time.

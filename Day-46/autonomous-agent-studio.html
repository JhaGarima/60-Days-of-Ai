Architecture Overview

Planner decomposes the brief into a strategic outline once. Executor drafts the full strategy from that outline. Then the loop begins: Evaluator scores the current draft against the rubric and target, Critic identifies concrete weaknesses in the evaluator's findings, and Improver rewrites the draft addressing every critique point — each call is a live, independent API request threaded with the full running history. The Safety Monitor screens each draft for unsupported claims or unsafe recommendations before it's shown. Memory Manager retains a compact summary of what changed each round so Improver never repeats a fixed mistake. The loop exits the instant a stop condition fires — plateau, threshold, or hard cap — and hands off to the Final Reviewer, which polishes and delivers the finished strategy.

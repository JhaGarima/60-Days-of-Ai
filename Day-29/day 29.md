# 📦 AI Supplier Negotiation Simulator

An AI-powered supply chain negotiation simulator that enables users to analyze supplier profiles, conduct multiple negotiation rounds, evaluate supplier performance, manage disruptions, and make strategic procurement decisions through an interactive AI-driven workflow.

## 🚀 Features

- 📄 Parses and analyzes supplier profiles
- 📊 Evaluates supplier strengths, weaknesses, and risks
- 🤝 Conducts AI-driven supplier negotiation rounds
- 💬 Generates realistic supplier responses
- 📈 Tracks negotiation progress and scoring
- ⚠️ Handles unexpected supplier and market scenarios
- 🎯 Assesses negotiation strategy effectiveness
- 🏭 Recommends optimal supply chain investments
- 📑 Provides detailed negotiation summaries
- 🧠 Uses Claude AI to power realistic procurement simulations

## 🛠️ Tech Stack

- Claude AI
- HTML
- CSS
- JavaScript

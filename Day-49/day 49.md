# Personal AI Playbook

Day 49 of the #60DaysABTalksChallenge

## Personal AI Playbook

An AI-powered system that interviews users about how they actually use AI, then generates a completely personalized AI workflow library instead of a collection of generic prompts.

The application discovers the user's profession, AI experience, daily tasks, preferred models, bottlenecks, goals, and workflow preferences before automatically building reusable prompt systems tailored to their needs.

## Features

- Interactive onboarding interview with one-question-at-a-time MCQs
- Personalized AI workflow generation based on user responses
- Smart workflow categorization
- Dashboard with personalized recommendations
- Prompt Builder using modular building blocks
- Loop Builder for converting prompts into autonomous iterative systems
- Live prompt preview
- Reusable prompt templates with editable variables
- Built-in examples and best practices
- One-click copy functionality
- Workflow search, filtering, and favorites
- Create, edit, duplicate, and delete workflows
- Local storage persistence
- Import and export workflow libraries
- Responsive design
- Dark and light mode
- Keyboard shortcuts
- Smooth animations
- Commercial SaaS-style interface
- Fully self-contained HTML file
- No external libraries or dependencies

## Prompt Builder

Build reusable prompts using modular components instead of writing prompts from scratch.

Available building blocks include:

- Role
- Objective
- Context
- Constraints
- Reasoning Strategy
- Output Format
- Tone
- Examples
- Quality Checks

Every block includes a clear explanation before selection and after insertion so users always understand its purpose.

## Loop Builder

Transform a standard prompt into an autonomous AI workflow by defining:

- Goal
- Evaluation Criteria
- Improvement Strategy
- Stop Conditions
- Safety Rules

This allows users to build repeatable AI systems instead of one-time prompts.

## Workflow Management

Users can:

- Save workflows
- Edit workflows
- Duplicate workflows
- Favorite workflows
- Search workflows
- Filter by category
- Organize their personal AI library
- Export backups
- Import existing libraries

# Hospital Admission Readiness Simulator

A web-based healthcare workflow simulator that evaluates a patient's readiness for hospital admission by analyzing documentation, insurance, clinical, and operational factors. The application allows users to simulate Prior Authorization workflows, identify admission risks, improve readiness through actionable steps, and generate a final admission decision.

---

## 🚀 Features

- Provider and physician information input
- Diagnosis and admission type selection
- Prior Authorization workflow simulation
- Admission readiness score calculation
- Documentation, insurance, bed, and clinical risk analysis
- Workflow actions to improve readiness
- Governance Snapshot overview
- Final admission decision with recommendations
- Multiple diagnosis scenario testing
- Fully client-side HTML application
  
---

## ▶️ How to Run

1. Clone or download the repository.
2. Open `Hospital_Admission_Readiness_Simulator.html` in any modern web browser.
3. Enter provider and physician details.
4. Select the diagnosis and admission type.
5. Configure Prior Authorization status and admission date.
6. Review the initial readiness assessment.
7. Complete workflow actions to improve readiness.
8. Analyze the Governance Snapshot.
9. Review the final admission decision.

# Day 20 - Face Puzzle Game

## Overview

Built an interactive Face Puzzle Game using HTML, CSS, and JavaScript with webcam integration. Users can capture a photo using their device camera and convert it into a playable puzzle. The application supports multiple difficulty levels, tracks performance, and maintains leaderboard records.

## Features

* Webcam photo capture
* Real-time image-based puzzle generation
* Multiple difficulty levels (3×3, 4×4, 5×5)
* Drag-and-drop puzzle interactions
* Touch support for mobile devices
* Move counter
* Timer tracking
* Best-time leaderboard
* Responsive user interface
* Play Again and New Photo functionality

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* MediaDevices API (Webcam Access)
* Local Storage

## Implementation Steps

1. Generated the complete Face Puzzle Game application.
2. Saved the HTML file locally.
3. Opened the application in a web browser.
4. Granted webcam permissions.
5. Captured a photo using the camera.
6. Selected puzzle difficulty.
7. Tested drag-and-drop functionality.
8. Verified timer and move counter.
9. Completed the puzzle.
10. Checked leaderboard updates and result tracking.

## Key Learnings

* Working with browser webcam APIs
* Handling image capture in web applications
* Implementing puzzle game logic
* Managing drag-and-drop interactions
* Tracking user performance metrics
* Using Local Storage for persistent data
* Creating responsive and interactive UI components

## Results

Successfully generated and tested a fully functional Face Puzzle Game with webcam integration, multiple puzzle sizes, performance tracking, and leaderboard functionality.
